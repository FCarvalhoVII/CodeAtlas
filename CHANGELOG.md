# Changelog

All notable changes to CodeAtlas are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases use [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-18

### Added

- Safe POSIX repository scanning with gitignore support, bounded reads, and Python AST parsing.
- Incremental SQLite indexing with deterministic offline and OpenAI embedding providers.
- Repository-scoped vector retrieval, metadata reranking, and overlap deduplication.
- Grounded structured answers with application-validated evidence citations.
- Typer CLI for index, search, ask, status, and repository-scoped removal.
- Bounded embedding concurrency, cancellation cleanup, partial-batch diagnostics, and transient embedding retries.
- Structured logging with credential, source, prompt, question, context, and model-output redaction.
- Reproducible local benchmark, release checklist, architecture documentation, and clean-wheel CI smoke test.
